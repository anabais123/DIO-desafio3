# DIO-desafios

## Criando um Star Schema para cenários de venda com power BI
### O projeto consistiu na reestruturação do modelo transacional para um modelo em estrela (Data Warehouse), definindo a tabela fato centrada no professor e as respectivas tabelas dimensão (Departamento, Curso, Disciplina, Pré-requisitos e Calendário/Data), removendo dados desnecessários de alunos e otimizando as chaves e métricas para análise.
